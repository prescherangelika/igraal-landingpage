# Marketing

Mein Sammelort für Marketing-Ideen rund um Astrotante – zum Spaß, ohne Druck.

## Idee

Angelehnt an Ruben Hassids „Level 4“: Statt NotebookLM nutze ich Claude Code + GitHub als
eigene Wissensbasis. Ich sammle Transkripte von Videos/Podcasts, die mich interessieren, und
lasse Claude daraus Antworten und Ideen ziehen – mit Quellenangabe.

## Ordner

| Ordner | Inhalt |
|---|---|
| `quellen/` | Transkripte, ein Unterordner pro Person (z. B. `quellen/alex-hormozi/`) |
| `prompts/` | Fertige Prompts zum Kopieren |
| `notizen/` | Meine Notizen und Zusammenfassungen |

## So starte ich wieder

1. Claude Code in diesem Repo öffnen.
2. Schreiben: „Lies `marketing/CLAUDE.md` und lass uns weitermachen.“
3. Transkripte hinzufügen: Prompt aus `prompts/youtube-wissensbasis.md` verwenden
   oder Transkript bei YouTube über „Transkript anzeigen“ kopieren und einfügen.
